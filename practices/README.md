# practices/

Working conventions read on demand (not auto-loaded). Current contents:

- `commands.md` — when/how the custom slash commands compose into the
  daily/weekly rhythm; the command table is the quick reference.
- `tasks.md` — the task grammar (emoji checkbox format), recurrence
  semantics, section routing, Finished/archive flow, engine operations.
- `plan-driven-workflow.md` — the plan lifecycle convention, generalized
  for any project.
- `project-scaffold.md` — standard project directories: debug
  walkthroughs, incremental tests, docs, notebooks.
- `tmux-organization.md` — session/window layout conventions across your
  machines.

Add a new practice file when a convention has bitten twice; link it here
and from CLAUDE.md's reference list if sessions should find it.
